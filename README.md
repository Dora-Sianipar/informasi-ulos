# UlosKita — Katalog Digital Ulos Batak

Mini project portofolio web development untuk mengenalkan ragam kain ulos Batak melalui katalog yang responsif dan interaktif.

## Fitur
- Menampilkan 8 contoh jenis ulos beserta ringkasan makna dan penggunaannya.
- Pencarian berdasarkan nama, makna, dan deskripsi.
- Filter kategori.
- Simpan/hapus ulos favorit menggunakan `localStorage`.
- Dialog detail untuk membaca informasi lebih lengkap.
- Tampilan responsif untuk desktop dan perangkat mobile.

## Teknologi
- HTML5
- CSS3 (Grid, Flexbox, media queries)
- JavaScript (DOM, event handling, array methods)
- Browser Local Storage

## Cara menjalankan
1. Unduh atau clone repository.
2. Buka folder proyek.
3. Klik dua kali `index.html`, atau buka dengan ekstensi Live Server di Visual Studio Code.
4. Tidak membutuhkan instalasi backend atau database.

## Pengujian manual
- [ ] Katalog menampilkan delapan kartu ulos.
- [ ] Pencarian menemukan data yang sesuai.
- [ ] Filter kategori mengubah hasil katalog.
- [ ] Tombol favorit menambah dan menghapus item.
- [ ] Favorit tetap tersimpan setelah halaman dimuat ulang.
- [ ] Tombol detail membuka informasi ulos yang benar.
- [ ] Dialog dapat ditutup melalui tombol X atau klik area luar.
- [ ] Tampilan tetap terbaca pada layar ponsel.

## Catatan akurasi konten
Deskripsi pada proyek ini merupakan ringkasan edukatif untuk demonstrasi antarmuka. Makna dan tata cara penggunaan ulos dapat berbeda menurut konteks adat, wilayah, dan sumber budaya. Sebelum dipakai sebagai sumber akademik atau publikasi resmi, verifikasi setiap keterangan dengan narasumber adat atau referensi budaya tepercaya.

## Pengembangan berikutnya
- Menambahkan foto ulos asli dengan izin penggunaan yang jelas.
- Menyediakan halaman admin untuk mengelola data.
